# Анализ финансовых транзакций и клиентов

## Описание
Проект включает обработку данных о транзакциях (`transactions_data.xlsx`) и клиентах (`clients_data.json`), их анализ, 
визуализацию и прогнозирование спроса.

---

### Виртуальне окружение для python
```bash
source venv/bin/activate
```
### Установка зависимостей
```bash
pip install -r requirements.txt 
```

### Запуск с пoмощью модуля main
```bash
python main.py
```
