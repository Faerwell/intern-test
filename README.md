# Документация к анализу финансовых транзакций и клиентов

## Описание
Проект включает обработку данных о транзакциях (`transactions_data.xlsx`) и клиентах (`clients_data.json`), их анализ, 
визуализацию и прогнозирование спроса.

---

### Виртуальне окружение для python и установка зависимостей
```bash
source venv/bin/activate
pip install -r requirements.txt 
```
### Запуск с пмощью модеуля main
```bash
python main.py
```
